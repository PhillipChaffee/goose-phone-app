Goose Mobile — style gallery

Every frame is a live 390×844 viewport (iframe) whose only stylesheet is ../assets/main.css, linked — not copied. Each frame reproduces the app's mount chain <body> > #main > .app with the screen's <header>/<main>/<footer> as unwrapped flex children, so 100dvh, vh/vw maxima, position:fixed modals and the flex-shrink:0 topbar/composer/tabbar contract all behave exactly as on device. Frames scroll internally; a few are pre-scrolled (noted below the label).
