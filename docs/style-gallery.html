goose mobile — style gallery

Generated, not written. Every frame below is the real .app subtree captured out of the running app by src/domdump.rs and written here by scripts/capture-gallery.py. Do not edit this file by hand — a hand-maintained copy is what drifted from the app last time. A phone frame is a 402×874 viewport (iPhone 17 Pro) linking the design system and every feature sheet; a desktop frame is the 1180×820 window src/main.rs opens, and links ../assets/desktop.css and ../assets/platform/macos.css after them, in the order src/app.rs emits them. So the styling is exactly what ships, on either shell. Frames render in whichever colour scheme your OS is set to; check both.

The traffic lights are AppKit's, not the app's. A desktop frame shows an empty .traffic-slot where macOS paints them, so this can say nothing covers that reservation and nothing about whether the reservation is where the lights really are. That stays a device check.

Safe-area insets are zero here — a browser has no notch — so the floating chrome sits higher than it does on a device. Positions are not what this is for; colour, type, spacing and state are.
